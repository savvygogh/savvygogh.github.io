Privacy

This is a personal controller for its owner's Tesla energy site. It reads energy-site settings and changes the energy-export preference. It does not request vehicle-control permissions.

Access tokens, refresh tokens, and site information are stored locally on the owner's computer. This static website does not store them. The hosting provider may retain access logs, including the temporary OAuth callback URL. There is no analytics code.

Access can be revoked in the owner's Tesla account. Local credentials can be removed by deleting the controller's private data directory after stopping the controller.
